ONT Optic and MAC Address Data Report Dashboard

========================================

This project provides a web dashboard to display and download generated ONT Optical and MAC Address reports.



The dashboard is built using Django and reads generated report files from the report directory.





Features

=======

\- View generated ONT Data reports

\- View generated MAC Address reports

\- Download reports directly from the dashboard

\- Simple web interface for report monitoring





Technologies

==========

-Django

-Python

-Bootstrap

-Excel (.xlsx)





Run Development Server

====================

Start the Django development server:

python manage.py runserver



Default access URL:

http://127.0.0.1:8000
